# Graphic Design — Exhaustive Resource Catalog

> Research plan / resource inventory for the "Graphic Designing" item in the
> LearningRoadmap README (Mahesh953-hub/LearningRoadmap). This is a
> **discovery catalog**, not a tutorial — a future agent should use this to
> build actual notebooks, exercises, and study docs. Every item lists a URL,
> a one-line description, and Free/Paid status. Research date: 2026-08-25.

## Intro

Graphic design spans visual theory (color, typography, layout/grid,
composition), software craft (raster tools like Photoshop/GIMP, vector tools
like Illustrator/Inkscape/Affinity Designer, all-in-one tools like Canva and
Figma), and applied disciplines (branding/logo design, social media kits,
posters, illustration basics). The good news: nearly every layer of this
stack has excellent **free** material — official app tutorials, YouTube
channels, open courses, and huge free-asset libraries — with paid
courses/subscriptions mostly useful for structured, project-based deep dives
(Skillshare, Domestika, Udemy) once fundamentals are in place. The list below
is organized by category; a suggested learning order follows at the end.

### Composition, Layout & Grid Systems
- https://ixdf.org/literature/topics/grid-systems — Interaction Design Foundation's collection of articles on grid systems in design. **Free**
- https://ixdf.org/literature/article/how-to-use-grid-systems — Practical explainer on manuscript, column, modular, and baseline grids. **Free**
- https://en.wikipedia.org/wiki/Grid_(graphic_design) — Overview article on the history and function of the grid in graphic design. **Free**
- https://madegooddesigns.com/grid-systems-graphic-design/ — Approachable modern explainer on grid systems (columns, gutters, baseline grid, responsive grids). **Free**
- *Grid Systems in Graphic Design* by Josef Müller-Brockmann — the foundational manual for grid-based layout (8–32 field grids, 3D grids); considered a must-read classic. **Paid** (book)
- https://lawsofux.com/ — Jon Yablonski's "Laws of UX": 21 psychology-based principles (Jakob's Law, Fitts's Law, Hick's Law, Gestalt principles, proximity, similarity, Von Restorff effect, aesthetic-usability effect) — directly useful for layout/composition decisions. **Free**
- https://www.explorersdesign.com/design-principles-cheatsheet/ — A visual cheat sheet of core design principles (balance, contrast, alignment, repetition, proximity, hierarchy). **Free**

## 10. Practice Project Ideas (progressively harder)

1. **Personal mood board / color-palette study** — pick 3 color palettes from Color Hunt and design 3 simple posters using each, to internalize color theory.
2. **Typography poster** — recreate a famous quote using only type (no images) practicing hierarchy, contrast, and grid alignment.
3. **Icon set** — design a consistent 8–12 icon mini-set (stroke width, corner radius, grid) in Inkscape/Illustrator/Figma.
4. **Personal logo / monogram** — design 3-5 concepts for your own initials-based logo, then refine one into final vector artwork with a one-page style guide (colors, fonts, spacing rules).
5. **Business card + letterhead** — extend the logo into a minimal print stationery set, learning bleed/margins/print-ready export.
6. **Social media kit** — design a cohesive Instagram post + story template set (3-5 templates) for a fictional small business, in Canva or Figma.
7. **Event poster** — design a full poster for a fictional concert/conference, practicing large-scale typographic hierarchy and grid layout.
8. **Full brand identity project** — invent a fictional brand (name, mission), then design: logo suite (primary/secondary/icon), color palette, type system, business card, social template, and a one-page brand guideline document. This is the flagship "portfolio piece" project.
9. **Redesign challenge** — pick an existing real brand/poster/app icon you find weak and redesign it from scratch, writing a short rationale (great Behance/Dribbble-style portfolio post).
10. **100 Days of Daily UI / Daily Design challenge** — sustained daily practice (see Section 6) to build speed, range, and a large portfolio body of work.

## Suggested Learning Progression

### Beginner (Weeks 1-4): Foundations + one tool
1. Read/skim core theory: **Laws of UX**, a color-theory primer (Tuts+ or ColorSchemer), **Practical Typography**, and a grid-systems explainer (IxDF).
2. Pick ONE beginner tool to get comfortable with software mechanics fast: **Canva** (fastest, template-driven) or **GIMP/Inkscape** (if you want raster/vector fundamentals free and portable).
3. Do the Envato Tuts+ or Adobe official beginner tutorial series for that tool.
4. Practice projects 1-3 from Section 10 (mood board, typography poster, icon set).
5. Join r/graphic_design and one Discord (Design Buddies) to start absorbing critique culture.

### Intermediate (Months 2-4): Vector + branding fundamentals
1. Learn a vector tool properly: **Inkscape** (free) or **Affinity Designer** (paid, one-time) — follow official tutorials end-to-end.
2. Take **Coursera's "Fundamentals of Graphic Design" (CalArts)** and **Typography by Ellen Lupton** (audit free).
3. Study real brand identities on **Brand New** and **Fonts In Use**.
4. Do practice projects 4-6 (logo, stationery, social kit).
5. Start a **Daily UI / 100-day challenge** for volume and speed.
6. Build a free asset toolkit habit: Google Fonts + Fontshare for type, Noun Project/Iconoir for icons, Unsplash/Pexels for photos, Coolors/Adobe Color for palettes.

### Advanced (Months 4+): Full brand systems + specialization
1. Learn raster mastery in **Photoshop or GIMP** (PiXimperfect for advanced techniques).
2. Read *Grid Systems in Graphic Design* (Müller-Brockmann) and *Thinking with Type* (Lupton) for deeper theory.
3. Complete the flagship **full brand identity project** (Section 10, item 8) as a portfolio centerpiece.
4. Consider one high-quality **paid** course for structured feedback: a Domestika branding course or Skillshare's Brand Identity & Logo Design path, or The Futur Academy for design-business skills.
5. Publish work on **Behance/Dribbble**, gather feedback from Design Buddies/r/graphic_design_critiques, and iterate.
6. Optionally branch into digital illustration (Krita/Procreate) or UI-adjacent brand systems (Figma) depending on interest overlap with the roadmap's other items (HTML/CSS/mockups, Android/Material You design).
