# Learning Roadmap — Resource Plan Index

This directory is the **resource-discovery plan** for the 7 learning goals listed in
the top-level [README.md](../../README.md). It was produced by running one dedicated
research pass per goal across the open internet, cataloguing every worthwhile
resource that exists for that topic today.

**What this is:** an exhaustive, categorized inventory of sites, docs, courses
(free and paid), interactive labs/sandboxes, GitHub repos worth studying or cloning,
forums/communities, YouTube channels, practice-project ideas, tools, and cheat sheets
— for each of the 7 fields, with a real URL and a one-line description on every entry.

**What this is NOT:** this is not the learning material itself. No notebooks, no
lessons, no explanations of the concepts are written here — this is the map, not the
territory. The next step (separate, future work) is for a dedicated research agent to
take this map, do the deepest possible pass through it, and actually build the
learning notebooks/docs — written simply enough that a 5-year-old could follow along
— and commit those to this repository.

Each plan file follows the same shape:

- A short intro on what the field is and why it's worth learning.
- Category-by-category resource lists (official docs, free/paid courses, interactive
  labs and sandboxes, GitHub repos to study or clone, communities, YouTube channels,
  practice-project ideas, tools, cheat sheets, and field-specific extras).
- Every single entry has a real URL, a one-line description, and a clear **Free** or
  **Paid** label.
- A suggested beginner → intermediate → advanced progression through the resources
  listed, so the next agent has an ordering to follow, not just a pile of links.

## Next step for whoever picks this up next

1. Read all 7 plan files in this directory in full.
2. For each field, go deeper than this pass did: actually work through the highest-value
   resources identified here, pull out the concrete knowledge, and build real,
   beginner-friendly learning material from it — notebooks where hands-on code/exercises
   make sense (Rust, APIs, LLM training, agents, Android/Flutter/Kotlin), and clear
   illustrated docs where the field is more visual/conceptual (HTML/CSS/mockups,
   graphic design).

   examples, no unexplained jargon, one idea at a time.
4. Save/commit the resulting notebooks and docs to this repository's `main` branch,
   organized by field, alongside (not replacing) this resource-plan directory.
